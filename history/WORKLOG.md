## 2026-11-04 — BPMN parser, validator, path enumeration, CLI and tests

**Prompt:** Build a Python solution that parses `src/data/invoice.bpmn` into a graph, keeps sequence-flow conditions verbatim, prints every start-to-end path with its conditions, handles the loop without recursion, rejects `invoice-broken.bpmn` with element IDs, and has pytest tests.

**Done:**
- Inspected both files; diffed them to find the defects (see below).
- `pyproject.toml` (no runtime deps; dev: pytest, ruff, mypy), `uv.lock`, `README.md`.
- `src/bpmn_paths/`: `model.py` (Node/Flow/ProcessGraph/Issue/errors), `parser.py` (ElementTree), `validation.py`, `paths.py` (iterative DFS), `cli.py`, `__main__.py`.
- `tests/`: 29 tests across parser, validation (one test per defect), paths, CLI.
- `CLAUDE.md`: hard rules (no fabricated test results, never modify `src/data/*.bpmn`, stdlib only). `.claude/settings.json`: deny Edit/Write on `src/data/**`.
- Installed uv 0.13.7 (winget, user scope) and Python 3.12.16 via uv, with the user's approval.

**Defects in `invoice-broken.bpmn`:**
1. `SequenceFlow_2` has `targetRef="ServiceTask_9"`, which doesn't exist (valid file: `ServiceTask_1`). Follow-on: `ServiceTask_1` still declares `<incoming>SequenceFlow_2</incoming>` and has no incoming flow.
2. Sequence flow `reviewNotSuccessful` (`reviewSuccessful_gw` → `invoiceNotProcessed`, `${!clarified}`) and its `<incoming>`/`<outgoing>` refs are removed. End event `invoiceNotProcessed` has no incoming flow, and diverging gateway `reviewSuccessful_gw` has only one exit.

**Decisions:**
- "Every path" = simple paths (no node repeated). A flow back to a node already on the path is not followed again and is reported as a loop flow (`reviewSuccessful`). Valid file → **2 paths**.
- All issues are collected (not fail-fast). Reachability runs only if local checks pass, because on the broken file it added 10 follow-up errors that hid the root causes.
- Conditions are stored as raw `conditionExpression` text (no strip, no evaluation); `None` when absent.

**Verification:** `uv run pytest` → 29 passed. `ruff format --check`, `ruff check`, `mypy --strict src tests` → clean. The first run had 3 failures: one wrong expected count in my test (the file has 10 flows, not 11), and two from noisy reachability output, fixed by the staging decision above. `git status` shows no changes to `src/data/`.

**Open items:** `uv python install` printed a link error for the minor-version alias, but the venv works (Python 3.12.16). uv isn't on `PATH` in already-open shells until they restart.

**Commit:** this commit (together with FINAL_RESULT.md, see next entry)
